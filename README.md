# Java Upskilling

A collection of Java projects and coding challenges documenting my journey of learning and improving my Java programming skills.

Each project has its own repository and focuses on practising different Java concepts.

## Projects

### 1. GitHub User Activity

A CLI application that fetches and displays a GitHub user's recent public activity.

**Topics:** Java HTTP Client, JSON processing, Collections, Generics, Enums.

[View Repository](https://github.com/idavyd/GH-User-Activity)

### 2. Task Tracker

A CLI application for managing tasks and tracking their status.

**Topics:** Collections, File I/O, Packages, Interfaces, Enums.

[View Repository](https://github.com/idavyd/Task-Tracker)

### 3. Number Guessing Game

A command-line game where the player tries to guess a randomly generated number.

**Topics:** Loops, Methods, Scanner, Random, Exception Handling.

[View Repository](https://github.com/idavyd/Guess-Game)

Build practical experience with Java, strengthen programming fundamentals, and gradually explore more advanced topics.
